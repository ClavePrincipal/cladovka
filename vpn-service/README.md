# VPN-сервис с продажей через Telegram-бота

Готовый каркас коммерческого VPN для РФ/СНГ:

- **Протокол VLESS + Reality (Xray)**: трафик неотличим от обычного HTTPS, хорошо переживает блокировки.
- **Панель Remnawave** управляет серверами (нодами) и пользователями, выдаёт ссылку-подписку.
- **Telegram-бот** (этот репозиторий, папка `bot/`) продаёт подписки, принимает оплату, сам создаёт и продлевает доступ.

```
 Клиент ──► Telegram-бот ──► ЮKassa / CryptoBot (оплата)
                │
                ▼  REST API
        Панель Remnawave ──► Ноды (VPN-серверы, Xray VLESS Reality)
                │                     ▲
                └── ссылка-подписка ──┘  клиент подключается через Happ / v2RayTun / Hiddify
```

## Что умеет бот

| Для клиентов | Для вас (админа) |
|---|---|
| Пробный период (по умолчанию 3 дня, один раз) | Уведомление о каждой оплате |
| Тарифы 1/3/6/12 мес. со скидкой за срок | `/stats`: пользователи, активные подписки, выручка за 30 дней |
| Оплата картой/СБП (ЮKassa) или криптой (CryptoBot) | `/user <id>`: карточка клиента |
| Доступ включается сам за 10–20 сек после оплаты | `/give <id> <дней>`: подарить дни |
| Продление суммирует дни | `/broadcast`: рассылка всем (ответом на сообщение) |
| «Мой VPN»: срок, ссылка, кнопка «Подключить» | |
| Инструкция по приложениям | |
| Реферальная программа (+7 дней за оплатившего друга) | |
| Напоминания за 3 дня, за 1 день и при окончании | |

Надёжность:
- оплата **проверяется напрямую через API провайдера**, поэтому подделать «успешный платёж» нельзя и публичный webhook не нужен;
- платёж зачисляется **ровно один раз**, даже если клиент жмёт «Я оплатил» одновременно с фоновой проверкой;
- если панель временно недоступна, платёж не теряется: бот повторит зачисление сам;
- если база бота потерялась, клиенты находятся в панели по `tg_<telegram_id>`.

## Запуск по шагам

### Шаг 1. Серверы

Минимальная схема на старте: **2 сервера**.

| Сервер | Для чего | Конфигурация |
|---|---|---|
| **Панель + бот** | Remnawave panel, страница подписки, бот | 2 vCPU, 2–4 ГБ RAM, 20+ ГБ диск |
| **Нода** (1 и больше) | Сам VPN (Xray) | 1–2 vCPU, 1–2 ГБ RAM, **канал 1 Гбит/с без лимита трафика** |

Главное для ноды не процессор, а канал и безлимитный трафик. Один активный пользователь тратит в среднем 30–150 ГБ в месяц (видео съедает больше всего).

**Где брать (для аудитории из РФ)**
- Локации: Нидерланды, Германия, Финляндия, Швеция, Польша. У них низкий пинг из РФ.
- Хостинги, которые часто используют для VPN и которые принимают карты РФ или крипту: **Aéza, PQ.Hosting, VDSina, 4VPS**. **Hetzner** стабилен, но не принимает карты РФ.
- В правилах хостинга (ToS) должно быть разрешено размещать VPN/прокси.

**Важно:** РКН время от времени замедляет целые подсети хостеров. Прежде чем платить за год, возьмите ноду на месяц. Проверьте скорость с разных операторов (МТС, Билайн, МегаФон, Т2, Ростелеком и домашний интернет). Держите 2+ ноды у разных хостеров, чтобы при проблемах с одной клиенты переключались на другую.

ОС: **Ubuntu 22.04/24.04** или **Debian 12**.

### Шаг 2. Домены

Купите домен (например на reg.ru или Namecheap) и создайте A-записи на IP сервера панели:
- `panel.вашдомен.com` для панели;
- `sub.вашдомен.com` для ссылок-подписок (их видят клиенты).

### Шаг 3. Панель Remnawave

Установите панель **по официальной инструкции: <https://docs.rw>** (раздел Installation → Panel). Там есть docker-compose, переменные окружения и настройка reverse-proxy с HTTPS.

После установки:
1. Зайдите в панель и создайте админа.
2. **Config Profiles**: создайте профиль на основе [`xray/vless-reality-profile.json`](xray/vless-reality-profile.json):
   - `privateKey`: сгенерируйте ключи Reality прямо в панели или командой `xray x25519`;
   - `shortIds`: любая hex-строка, например вывод `openssl rand -hex 8`;
   - `REPLACE_SNI_DOMAIN`: сайт-«маскировка». Это должен быть популярный зарубежный сайт с TLS 1.3 и HTTP/2, желательно в той же сети, что и нода. Подходящий удобно искать утилитой *RealiTLScanner*, запустив её на ноде.
3. **Internal Squads**: создайте сквад (например `Default`) и добавьте в него inbound `VLESS_REALITY`.
4. **API Tokens**: создайте токен для бота.
5. В настройках панели включите **лимит устройств (HWID)**, если хотите ограничивать число устройств (`HWID_DEVICE_LIMIT` в боте).

### Шаг 4. Ноды

Для каждой ноды:
1. В панели: **Nodes → Create**. Укажите IP ноды и профиль из шага 3. Панель покажет `docker-compose.yml` для ноды с её секретным ключом.
2. На сервере ноды установите Docker (`curl -fsSL https://get.docker.com | sh`), вставьте этот compose и запустите `docker compose up -d`.
3. В панели: **Hosts → Create**. Это то, что попадёт в подписку клиента: адрес ноды, порт 443, inbound `VLESS_REALITY`, понятное имя вроде `🇳🇱 Нидерланды`.

Проверка: создайте в панели тестового пользователя, откройте его ссылку-подписку в Happ или v2RayTun и убедитесь, что VPN работает.

> Подробно про ноды и хосты: <https://docs.rw> (Installation → Node).

### Шаг 5. Telegram-бот

1. В **@BotFather**: `/newbot` → получите токен. Там же задайте описание (`/setdescription`) и аватарку (`/setuserpic`).
2. Создайте отдельный аккаунт или бота для поддержки и запишите его username.

### Шаг 6. Платёжки

**CryptoBot (крипта, самый простой вариант)**
1. Откройте @CryptoBot → *Crypto Pay* → *Create App*.
2. Скопируйте API Token в `CRYPTOBOT_TOKEN`.
3. Цены в боте указаны в рублях, клиент платит эквивалент в USDT/TON/BTC по курсу.
4. Для теста без денег есть @CryptoTestnetBot и `CRYPTOBOT_TESTNET=true`.

**ЮKassa (карты РФ, СБП)**
1. Зарегистрируйте магазин на yookassa.ru (нужен ИП, самозанятость или ООО).
2. В личном кабинете возьмите `shopId` и создайте секретный ключ.
3. ⚠️ ЮKassa и другие российские эквайеры **часто отказывают VPN-проектам или блокируют их**. Код устроен так, что другой провайдер подключается одним классом в `bot/app/payments.py` (Platega, Lava, Telegram Stars и т.д.). Напишите, какой нужен, и я добавлю.
4. Если в магазине включены чеки по 54-ФЗ, укажите `YOOKASSA_RECEIPT_EMAIL`.

### Шаг 7. Запуск бота

На сервере панели:

```bash
git clone <этот репозиторий> && cd <репозиторий>/vpn-service/bot
cp .env.example .env
nano .env                 # заполните токены и настройки
docker compose up -d --build
docker compose logs -f    # должно быть: «Панель Remnawave доступна, сквадов: 1»
```

Откройте бота, нажмите `/start`, возьмите пробный период и проверьте подключение. Потом купите самый дешёвый тариф и проверьте оплату.

Обновление бота: `git pull && docker compose up -d --build`.
Бэкап: база лежит в docker-томе `bot-data`, а главное (пользователи и сроки) хранится в панели Remnawave. Бэкапьте прежде всего её базу (PostgreSQL панели).

## Настройка

Все настройки задаются в `.env` (полный список с комментариями в [`bot/.env.example`](bot/.env.example)):

| Переменная | По умолчанию | Что это |
|---|---|---|
| `TARIFFS` | `30:199,90:549,180:999,360:1790` | `дней:цена`. Скидку бот считает и показывает сам |
| `TRIAL_DAYS` | `3` | пробный период, `0` выключает |
| `REFERRAL_BONUS_DAYS` | `7` | бонус за приглашённого, `0` выключает |
| `HWID_DEVICE_LIMIT` | `3` | лимит устройств на подписку |
| `TRAFFIC_LIMIT_GB` | `0` | лимит трафика в месяц, `0` значит безлимит |
| `REMNAWAVE_SQUAD_UUIDS` | все | какие группы серверов выдавать клиентам |

Все тексты бота собраны в одном файле `bot/app/texts.py`, их можно править под свой бренд.

## Разработка

```bash
cd vpn-service/bot
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest            # 40 тестов: логика, HTTP-форматы API, сквозной сценарий бота
```

Структура:

```
bot/app/
  __main__.py     запуск, сборка зависимостей
  config.py       настройки из .env, тарифы
  db.py           модели: User, Payment
  remnawave.py    клиент API панели
  payments.py     CryptoBot, ЮKassa (интерфейс для новых провайдеров)
  service.py      бизнес-логика: продление, оплаты, триал, рефералка, напоминания
  handlers/       экраны бота и админ-команды
  tasks.py        фоновые проверки оплат и напоминания
  texts.py        все тексты
```

## Экономика (пример)

| Статья | ₽/мес |
|---|---|
| Сервер панели | ~400 |
| 2 ноды | ~1000 |
| Домен | ~50 |
| **Итого** | **~1 500** |

При цене 199 ₽/мес расходы окупаются примерно с 8–10 платящих клиентов (учитывая комиссии платёжек в несколько процентов). Одна нода с каналом 1 Гбит/с обычно тянет 100–300 активных пользователей, дальше добавляйте ноды.

## Юридические риски

Это не юридическая консультация, но знать нужно:
- В РФ VPN-сервисы обязаны подключаться к ФГИС и блокировать запрещённые ресурсы, а с 2024 года запрещена реклама способов обхода блокировок. Продажа VPN для обхода блокировок находится в серой зоне.
- Отсюда отказы и блокировки у российских эквайеров. Крипта (CryptoBot) в этом смысле надёжнее.
- Рекламу продвигайте осторожно. Площадки в РФ могут отказать или удалить объявления.
- Опубликуйте оферту (`OFFER_URL`) с условиями возврата и запретом на незаконное использование.
- В Xray-профиле по умолчанию заблокированы торренты, чтобы хостер не получал жалобы правообладателей и не блокировал сервер.

Перед масштабированием проконсультируйтесь с юристом.
