# NOIR — платформа онлайн-казино и букмекера

| Папка | Что внутри |
|-------|-----------|
| `web/` | Сайт для игроков. С сервером работает через API; без сервера открывается в демо-режиме с виртуальными деньгами |
| `admin/` | Бэк-офис (мониторинг): дашборд GGR/NGR и RTP, игроки, выплаты, платежи, AML, линия, аудит, сотрудники |
| `server/` | Node.js 22 + Fastify + PostgreSQL: деньги, игры, ставки, платежи, KYC, AML, лимиты, метрики |
| `deploy/` | Caddy (HTTPS), Prometheus + алерты, Grafana-дашборд, бэкапы |
| `docs/SECURITY.md` | Аудит безопасности и принятые меры |
| `docs/LAUNCH.md` | Что осталось до запуска: лицензия, партнёры, доработки, инструкция по развёртыванию |

**Продукт**
- Ставки на спорт: линия и Live, одинар и экспресс, «Экспресс дня» +10% от 4 событий, защита от изменения коэффициентов, возвраты.
- Казино: слоты 5×3 (RTP 95%), европейская рулетка (97,3%), Crash (96%), Мины (96%), Dice (98%). Все исходы считаются на сервере и проверяемы (Provably Fair).
- Маржа линии: топ-лиги 5%, Live 7%, остальные 8%.
- Кошелёк: депозит через страницу провайдера, вывод через проверку финансовым отделом, бонус 100% с вейджером ×30.
- Регистрация в 1 клик, по телефону, по e-mail, проверка возраста 18+, KYC.
- Ответственная игра: лимиты депозита и проигрыша, напоминания, самоисключение (действует и на новые аккаунты того же человека).
- Антифрод: вывод только на карту пополнения, один бонус на человека и карту, чарджбэки, задержка live-ставок, лимиты для «профессиональных» игроков, 2FA и защитная пауза после смены пароля. Подробно в `docs/SECURITY.md`.

Быстрый старт — в `docs/LAUNCH.md`.
