# NOIR Casino — прототип сайта

Открыть `index.html` в браузере. Всё работает без сервера, деньги виртуальные (демо).

**Что есть**
- Ставки на спорт: линия и Live (коэффициенты меняются), одинар / экспресс, «Экспресс дня» +10% от 4 событий, расчёт ставок по вероятностям. Маржа: топ-лиги 5%, Live 7%, прочие лиги 8%.
- Казино: слоты 5×3 на 10 линий (RTP ≈95%, проверено симуляцией), европейская рулетка (97,3%), Crash «Комета» (96%), Dice (98%), Мины (96%).
- Provably Fair: все исходы = SHA-256(серверный сид : клиентский сид : nonce), хэш показан заранее, сид раскрывается.
- Кошелёк: карты, Kaspi, Halyk, Apple/Google Pay, СБП, USDT, BTC, TON; история операций, бонус на первый депозит.
- Регистрация в 1 клик / по телефону / по e-mail, выбор валюты.
- Ответственная игра: лимит депозита, напоминания о времени, самоисключение.

**Для реальных денег нужно:** игровая лицензия, бэкенд (баланс и RNG только на сервере), платёжный провайдер, KYC/AML, фид спортивных коэффициентов, интеграция с провайдерами игр.
