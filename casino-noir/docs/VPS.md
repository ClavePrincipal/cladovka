# Тестовый сайт на своём сервере (VPS)

Результат: сайт по адресу `https://ваш-домен` с регистрацией, входом с любого устройства, тестовой оплатой и бэк-офисом.
Деньги не настоящие: оплата и проверка документов работают через песочницу. На сайте висит плашка «Тестовый режим».
Поисковики сайт не индексируют.

## Что понадобится

1. **Сервер (VPS)** с Ubuntu 24.04: от 2 ГБ памяти (лучше 4 ГБ), 2 процессора, 30 ГБ диска. Обычно $5–25 в месяц.
   Перед оплатой проверьте правила провайдера: многие запрещают сайты с азартными играми, даже тестовые.
2. **Домен** или поддомен, например `test.ваш-домен.kz`.

## Шаги

**1. Направьте домен на сервер.** В панели регистратора домена создайте запись:

| Тип | Имя | Значение |
|-----|-----|----------|
| A | `test` (или `@` для основного домена) | IP-адрес сервера |

Обновление DNS занимает от нескольких минут до пары часов.

**2. Подключитесь к серверу.** На Windows откройте PowerShell, на Mac — Терминал:
```bash
ssh root@IP-адрес-сервера
```

**3. Установите сайт** — три команды:
```bash
apt-get update && apt-get install -y git
git clone -b claude/casino-website-design-nzo80n https://github.com/ClavePrincipal/cladovka.git
cd cladovka/casino-noir && bash deploy/install.sh test.ваш-домен.kz ваш@email.com
```
Скрипт сам установит Docker, настроит файрвол, сгенерирует секреты, запустит сайт с HTTPS, добавит демо-линию матчей и создаст администратора.
Первый запуск занимает 3–5 минут.

**4. Сохраните данные администратора.** В конце скрипт покажет пароль и «TOTP secret». Они показываются один раз.
Откройте Google Authenticator (или 1Password) → «Добавить» → «Ввести ключ настройки» → вставьте TOTP secret.

**5. Готово.**
- Сайт: `https://test.ваш-домен.kz` — зарегистрируйтесь как обычный игрок, пополните счёт через тестовую страницу оплаты, играйте, делайте ставки.
- Бэк-офис: `https://test.ваш-домен.kz/admin/` — e-mail, пароль и 6-значный код из приложения.

Матчи в линии идут сами: начинаются по расписанию, завершаются примерно через 1 ч 45 мин, ставки рассчитываются, вместо сыгранных появляются новые.

## Полезные команды (в папке `cladovka/casino-noir`)

| Что сделать | Команда |
|-------------|---------|
| Обновить сайт до последней версии кода | `git pull && bash deploy/install.sh test.ваш-домен.kz ваш@email.com` |
| Посмотреть логи | `docker compose logs -f app` |
| Перезапустить | `docker compose restart` |
| Остановить | `docker compose down` |
| Добавить сотрудника | `docker compose exec app node src/scripts/create-staff.js email@x.kz "Имя" finance` |
| Открыть Grafana (мониторинг) | на своём компьютере `ssh -L 3000:127.0.0.1:3000 root@IP`, затем `http://localhost:3000` (пароль в файле `.env`, строка `GRAFANA_PASSWORD`) |

Бэкапы базы сохраняются каждый день в папку `backups/` (последние 14 дней). Файл `.env` содержит секреты: не публикуйте его и сохраните копию в надёжном месте.

## Если что-то не работает

- **Сайт не открывается по HTTPS.** Проверьте, что A-запись домена указывает на IP сервера (`ping test.ваш-домен.kz`). Сертификат выпускается автоматически, когда DNS обновится.
- **Скрипт пишет «Приложение не запустилось».** Пришлите вывод `docker compose logs app`.

## Перед запуском с реальными деньгами

Тестовый стенд не подходит для реальных денег. Нужны лицензия, платёжный провайдер, KYC-провайдер, рабочий режим (`NODE_ENV=production`) и шаги из `LAUNCH.md` и `SECURITY.md`.
