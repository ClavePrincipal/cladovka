# План запуска NOIR

Платформа готова технически: деньги, игры, ставки, платёжный слой, KYC, AML, лимиты, бэк-офис, мониторинг.
Ниже — что осталось, по порядку. Пункты, которые зависят от партнёров, помечены **[партнёр]**, от юристов — **[юрист]**.

## Этап 1. Юрисдикция и лицензия — 2–6 месяцев **[юрист]**

Сначала выберите, где работаете, — от этого зависят и лицензия, и партнёры, и налоги.

| Вариант | Что важно |
|---------|-----------|
| **Казахстан** | Онлайн-казино запрещены. Разрешены только букмекеры с лицензией АРРФР/МТС и подключением к Единому центру учёта ставок (ЕЦУП). Казино-раздел для РК нужно отключить через `BLOCKED_COUNTRIES` или отдельную сборку |
| **Кюрасао (CGA)** | Новый режим с 2024 года, 3–6 месяцев, нужен местный директор и AML-офицер |
| **Мальта (MGA)** | Самая уважаемая, 6–12 месяцев, высокие требования к капиталу и процессам |
| **Анжуан, Тобике** | Быстро и дёшево, но многие банки и провайдеры игр с ними не работают |

Нужны также: юрлицо, правила игры и бонусов, политика конфиденциальности, AML/KYC-политика, политика ответственной игры. Тексты на сайте — после юриста.

## Этап 2. Подключение партнёров

Код уже содержит интерфейсы. Для каждого партнёра — один адаптер.

| Что | Варианты **[партнёр]** | Где в коде |
|-----|------------------------|------------|
| Платежи: карты | эквайринг банка, Paysafe, Nuvei, Praxis Cashier (каскад из нескольких PSP) | `server/src/payments/providers.js` — добавить адаптер с `createDeposit`, `createPayout`, `verifyWebhook` |
| Платежи: локальные | Kaspi, Halyk, P2P-агрегаторы (если разрешено в юрисдикции) | там же |
| Криптовалюта | CoinsPaid, NOWPayments, Cryptoprocessing | там же |
| KYC | Sumsub, Veriff, Onfido | адаптер в `POST /api/kyc/start` возвращает URL провайдера; вебхук `/api/webhooks/kyc/:provider` уже есть и должен передавать `identityRef` (номер документа), по нему ищутся дубликаты и самоисключённые |
| Слоты и live-казино | агрегатор: SoftSwiss, Slotegrator, EveryMatrix, BetConstruct (дают сотни игр, Evolution, Pragmatic по одному API) | новый модуль «remote games»: кошелёк сервиса уже готов (ставка/выигрыш через `ledger.post` с идемпотентностью) |
| Линия и коэффициенты | Sportradar, Genius Sports, BetConstruct, OddsMatrix | заменить ручной ввод в «Линии» на импорт фида: `sport.create` / `sport.update` / `sport.settle`, поле `feed_ref` уже есть |
| SMS / e-mail | Twilio, Mobizon (KZ), SendGrid | подтверждение телефона и e-mail, восстановление пароля |

## Этап 3. Доработки, которые я рекомендую сделать до запуска

Это не блокеры технически, но без них сложно получить лицензию или масштабироваться.

1. **Восстановление пароля** по e-mail/SMS и подтверждение контактов (после подключения SMS/e-mail провайдера).
2. **Live-ставки с задержкой** (bet delay 3–8 секунд) и автоматической приостановкой рынка при опасном моменте — приходит с фидом.
3. **Ограничение по игрокам** (лимиты ставок для «профессиональных» игроков) — стандарт у букмекеров.
4. **Кэшбэк и турниры** — сейчас в UI как акции, нужна логика начисления (ежедневная задача по журналу операций).
5. **Отчёты для регулятора и бухгалтерии** — выгрузка GGR/NGR по дням, по играм, по странам (данные уже есть в `ledger`).
6. **Мультивалютность** — сейчас валюта выбирается при регистрации, но курсы и конвертация не реализованы.
7. **Мобильное приложение** — PWA (быстро, из этой же кодовой базы) или нативное. Apple и Google принимают гемблинг-приложения только от лицензированных операторов в разрешённых странах.
8. **Локализация** — казахский и английский языки.
9. **Чат поддержки** — Intercom, Zendesk, Jivo.

## Этап 4. Инфраструктура перед запуском

1. Сервер или облако в юрисдикции, которую требует регулятор (некоторые требуют данные в своей стране).
2. Управляемая PostgreSQL (с репликой и point-in-time recovery) вместо контейнера.
3. Секреты в Vault/KMS (см. `docs/SECURITY.md`).
4. Cloudflare перед сайтом, `BLOCKED_COUNTRIES` для запрещённых стран, `ADMIN_IP_ALLOWLIST` для офиса/VPN.
5. Алерты Prometheus → Telegram/Slack/PagerDuty дежурному.
6. Пентест и сертификация ГСЧ (см. `docs/SECURITY.md`).

## Параметры защиты (`.env`)

| Параметр | По умолчанию | Что делает |
|----------|--------------|------------|
| `AUTO_APPROVE_WITHDRAWAL` | 200 000 ₸ | Выплаты до этой суммы верифицированным игрокам без алертов и старше 24 часов уходят автоматически |
| `FOUR_EYES_WITHDRAWAL` | 2 000 000 ₸ | С этой суммы выплату одобряют два сотрудника |
| `LIVE_BET_DELAY_MS` | 5000 | Задержка приёма live-ставок |
| `SECURITY_HOLD_HOURS` | 24 | Пауза на вывод после смены пароля или 2FA |
| `CASHBACK_PCT`, `CASHBACK_MAX` | 10%, 1 000 000 ₸ | Еженедельный кэшбэк |
| `LOGIN_FAILS_PER_IP`, `LOGIN_FAILS_PER_ACCOUNT` | 5, 30 | Блокировка входа на 15 минут |
| `KYC_PROVIDER` | sandbox в разработке | Провайдер верификации; без него онлайн-KYC недоступен |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET` | — | CAPTCHA на регистрации и входе |
| `LICENSE_TEXT` | — | Текст лицензии в футере. Не заполняйте, пока лицензии нет |

Суммы в `.env` указываются в тиынах (×100).

## Как запустить сейчас

**Локально для разработки**
```bash
cd server && npm install
cp ../.env.example .env   # заполнить секреты, NODE_ENV=development, COOKIE_SECURE=false
npm run migrate && npm run seed
npm run create-staff -- you@company.kz "Ваше Имя" admin   # выдаст пароль и секрет 2FA
npm start                  # сайт: http://localhost:8080, бэк-офис: http://localhost:8080/admin/
npm test                   # нужна БД noir_test
```

**Тестовый стенд на сервере** — одна команда, пошагово в `docs/VPS.md`:
```bash
bash deploy/install.sh test.ваш-домен.kz you@company.kz
```
Скрипт проверен на полном Docker-стеке: HTTPS-прокси, два экземпляра приложения, база, бэкапы, Prometheus, Grafana.
В тестовом режиме (`NODE_ENV=development`) работают песочницы оплаты и KYC и демо-фид матчей.

**Рабочий запуск** — тот же `docker-compose.yml`, но `.env` заполняется вручную: `NODE_ENV=production`, реальные `PAYMENT_PROVIDERS` и `KYC_PROVIDER`, `ROBOTS_TAG=all`.
В `NODE_ENV=production` песочницы и демо-фид отключены автоматически. Администратор создаётся командой
`docker compose exec app node src/scripts/create-staff.js you@company.kz "Ваше Имя" admin`.
